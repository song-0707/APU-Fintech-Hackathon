# ASK COCO — Organizational Intelligence Q&A

**Ask Coco** is the natural language search and Q&A module for **Corporate Brain**. It allows users to ask natural language questions across all processed organizational meeting videos, audio recordings, decisions, action items, and transcripts.

Every answer generated by Coco includes **exact citations** referencing:
- Source meeting video filename
- Speaker name
- Precise timestamp (`HH:MM:SS`)
- Quote excerpt from the transcript

---

```text
ASK COCO/

```

---

## Features

1. **Natural Language RAG (Retrieval-Augmented Generation)**:
   - Reads all processed meeting results from `MEETINGS/results/*.json`.
   - Uses Gemini 2.5 Flash (`gemini-2.5-flash`) to synthesize clear, accurate answers.
2. **Exact Source Citations**:
   - Displays citation badges for every claim with speaker name, timestamp, and transcript excerpt.
3. **Interactive Starter Chips**:
   - Quick one-click queries for common organizational questions.
4. **Standalone & Integrated Execution**:
   - Can be served via FastAPI at `http://localhost:8100/ask-coco` or opened directly as `index.html`.

---

## API Endpoints

- **`POST /api/chat`**
  - **Request Body**: `{"query": "What did Samuel say about certificates?"}`
  - **Response**:
    ```json
    {
      "answer": "Samuel confirmed that...",
      "citations": [
        {
          "filename": "Build with AI with Md. Samiul Apon.mp4",
          "job_id": "f51496e885d6",
          "speaker": "Samuel",
          "timestamp": "00:00:08",
          "excerpt": "It's wise to post because we made it compulsory."
        }
      ]
    }
    ```

- **`GET /ask-coco`**
  - Serves the `ASK COCO/index.html` chat interface directly.
